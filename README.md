# Vitrine Menuiserie Compère

Site vitrine pour Emeric Compère, menuisier bois (Var & PACA) : catégories de
réalisations en cartes repliables, galerie photo, mode édition intégré
(sans authentification — persistance locale par navigateur) et installation
en PWA sur l'écran d'accueil.

Site en ligne : https://emericcompere-coder.github.io/compere-menuiserie-/
